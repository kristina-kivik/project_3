### Проект 3. Тестирование авторизации Kittygram



В рамках учебного проекта выполнена работа по дополнению тестовой документации и проведению ручного тестирования веб-приложения.



**Выполненные работы:**



* Анализ тестовой документации: изучена готовая декомпозиция интерфейса, а также выделенные классы эквивалентности и граничные значения для определения недостающих проверок.



* Составление тест-кейсов на вёрстку: разработаны и добавлены отсутствующие тест-кейсы Т2, Т4, Т10, Т16, Т20 и Т23 для проверки корректности отображения элементов интерфейса.



* Составление тест-кейсов на логику: разработаны и добавлены тест-кейсы Т3, Т5, Т8, Т10, Т13, Т24 и Т25 для проверки логики работы функциональности и обработки пользовательских данных.



* Ручное тестирование: выполнены составленные проверки на тестируемой реализации веб-приложения, проведено сравнение фактического результата с ожидаемым.



* Анализ результатов: проверена корректность работы интерфейса и функциональности в соответствии с подготовленными тест-кейсами.
